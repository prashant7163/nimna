# lib/

Dart source for the Nimna app. Layering per
`docs/architecture/app-architecture.md` §8.1 — dependency arrows point
down only; `diag` is importable by all layers and imports only `crypto`.

```
main.dart            async boot: bindings → bootstrap → runApp
l10n/                ARBs (EN template + DE/FR/ES/IT stubs until S16) and
                     the gen_l10n output (app_localizations*.dart,
                     regenerated by `flutter gen-l10n`, committed)
src/app/             composition + app root
  app.dart             NimnaApp: MaterialApp, themes, l10n, LockGate wiring
  bootstrap.dart       composition root (production defaults, test seams)
  app_scope.dart       NimnaServices + AppScope InheritedWidget (DI)
  lock_gate.dart       app-lock perimeter: replaces the whole Navigator
                       subtree while sealed (zero-leak rule)
  routes.dart          named routes (Navigator 1.0, onGenerateRoute)
  theme.dart           two ThemeData from the token map; button themes
  transitions.dart     fade + 8px drift, 320 ms decelerate; honors
                       MediaQuery.disableAnimations
src/ui/              screens + widgets
  theme/nimna_tokens.dart   NimnaTokens ThemeExtension — THE only file with
                            color literals; drift-guarded against
                            designs/system/tokens.json v1.1.0
  screens/channel_list_screen.dart  empty-state shell (voice string 4
                                    verbatim); S8: Create a code live via
                                    the G2 single entry, Enter a code still
                                    an S9 stub, boot-time pending-pairing
                                    resume on first frame; S13: the F4 footer
                                    Settings entry row
  screens/pairing/          the F2 initiator flow surfaces (S8):
                            create_line_flow.dart (phase-switching host +
                            lifecycle forwarding), create_code_setup_screen
                            (F2.1 + TTL sheet), share_code_screen
                            (F2.2/F2.4 one surface: QR + code simultaneous,
                            F2.3 share sheet w/ string 13, back-confirm,
                            waiting/bridged hold), code_ended_screen
                            (F2.8 expired · spent)
  screens/settings/    S13: settings_root_screen.dart (F8.1) and
                       app_lock_setup_screen.dart (F8.2 choose→confirm→
                       enroll; current-PIN gate → manage/turn-off)
  widgets/             S8 pairing widgets: qr_card (CustomPainter over the
                       qr matrix, true-white card), idle_line (dotted line
                       motif), nimna_toast (custom overlay toast),
                       nimna_back_button (painter chevron). S13 shared
                       design-system widgets: glyphs.dart (CustomPainter
                       icons, RTL-mirrored), nav_bar.dart, nimna_symbol.dart
                       (dot·line·dot), pin_pad.dart (PinDots + PinPad),
                       nimna_toggle.dart, destructive_hold_button.dart
                       (hold-to-wipe: burn, release-cancels, fires exactly
                       once), wipe_sheet.dart (full F8.3/string 8 +
                       per-channel F7.2 variants over one body)
src/pairing/         pairing flows — S8: initiator/ only (controller,
                     pending-pairings record, single-entry
                     create_line_entry, share + qr fenced call sites);
                     see src/pairing/README.md
src/protocol/        PURE §3.1.1/§3.1.2/§5.4 codec & derivation,
                     vector-locked; S10 owns §5.5+ (checkpoint fence);
                     see src/protocol/README.md
src/transport/       dart:io WebSocket relay transport + no-hammer
                     backoff policy; see src/transport/README.md
src/noise/           S9/S10 — from-spec Noise engines (XXpsk2 pairing +
                     KK session + §5.6 transport); see src/noise/README.md
src/session/         S10 — the live text session, decomposed per-concern:
  model/               Flutter-free immutable view/event leaf (MessageView,
                       ChatEvent, SessionLineState, PendingReaction)
  connection/          SessionController — the Flutter-free connection lane
                       (KK driver, delivery FSM, knock-accept gating [S12],
                       outbox flush, reconnect, media dispatch [S11])
  chat/                the chat UI (composer, message_bubble, message_actions,
                       chat_screen) — holds no transport/keys/store
                     see src/session/README.md
src/media/           S11 — media & documents: transfer/ (chunker +
                     reassembler over the frozen codec, receiver-bounded +
                     receiver-clock expiry), pipeline/ (on-device EXIF-strip
                     + compression via `image` in an isolate; the sole
                     file_picker/share_plus 2nd sites), ui/ (attach sheet,
                     media bubbles, viewer); see src/media/README.md
src/presence/        S12 — knock/presence/offline-compose/reconnect:
                     session_launcher (THE controller factory — wires media +
                     token sink + KNOCK payload), knock/incoming-knock
                     controllers, reconnect_coordinator (~20s live-drop),
                     background_grace (30s), push_opt_in (default OFF),
                     peer_token_store; see src/presence/README.md
src/billing/         S17 — on-device entitlement gate + paywall (StoreKit2/
                     Play Billing); billing absent from protocol/transport/
                     storage/crypto/wipe/lock (permanence fence)
src/lock/            S13 — the app-lock domain tier (imports storage/keys +
                     crypto, never ui):
  lock_controller.dart   state machine over KeyService: the only path to
                         open() once lock is enabled; seal on lifecycle
                         `hidden` (never `inactive`); in-memory escalating
                         retry delay (5 free, 1 s doubling, 30 s cap)
  lock_config_store.dart LockConfig blob (ver‖flags‖pin_len‖salt‖verifier)
                         + the SECOND (and last) flutter_secure_storage
                         call site — scope amendment, intake §3
  pin_verifier.dart      Argon2id verifier (spec §7 locked params, sodium
                         sumo pwhash) — gate-not-key; no byte-returning
                         API (test-enforced)
  biometric_gate.dart    the ONE local_auth call site; biometricOnly, PIN
                         pad is the fallback, never the OS credential
src/wipe/            S13 — wipe_service.dart: thin orchestration over the
                     S7 key-destruction-first primitives (zero new
                     destruction logic); full wipe also deletes the lock
                     config + reopens fresh; pre-channel-wipe hook seam
                     for the future session layer
src/domain/          models + repositories (record (de)serialization,
                     CRID index built at unlock, per-channel seq counter)
src/storage/         everything persistent
  keys/                KeyService (MK → store keys, sealed ⇄ open,
                       StorageSealedError) + the ONE flutter_secure_storage
                       call site (pinned Keychain accessibility)
  db/                  nimna.db open/schema/destructive-reset + row stores
                       (ciphertext blobs + the plaintext-column budget only)
                       + meta_records.dart (encrypted meta values under
                       k_meta; S8: the pending-pairings record)
  media/               encrypted blob files under <root>/media/
  backup/              iOS isExcludedFromBackup platform-channel client
  store_root.dart      <ApplicationSupport>/nimna-store/ — one root, one
                       exclusion point, one wipe point
  storage_service.dart open/seal/fullWipe/wipeChannel orchestration
src/crypto/          sodium init, RFC 5869 HKDF (vector-locked), the
                     ChaCha20-Poly1305-IETF at-rest AEAD glue, RecordCipher
                     (nonce‖ct, AD binding, per-record keys). S8/S9 Noise
                     engine lands here.
src/diag/            the encrypted ring-buffer diagnostic log: closed
                     DiagEvent/DiagCode enums (diag_events.dart is the whole
                     vocabulary — additions are a review event), fixed
                     integer-only binary encoding, 7-UTC-day file ring.
                     The public API accepts no String anywhere.
```

Rules that hold everywhere under `lib/`:

- Zero hardcoded user-facing strings — everything renders from the ARB
  layer (test-enforced by `test/ui/no_hardcoded_strings_test.dart`;
  reviewer remains the authority).
- No color literals outside `nimna_tokens.dart` (drift-guard-tested).
- No locale-dependent logic below `src/ui/` — protocol/storage/crypto code
  is locale-independent by definition.
- Only Session-2-locked crypto primitives; libsodium computes everything —
  `src/crypto/` is byte plumbing, never cryptography.
