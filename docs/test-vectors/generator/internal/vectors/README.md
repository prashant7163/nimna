# internal/vectors/

Emission of the five committed JSON vector files (see
[`docs/test-vectors/README.md`](../../../README.md) for what each proves):

- `vectors.go` — `Generate(outDir, wordlistPath)`: pins the wordlist
  SHA-256, orchestrates the five files, and holds the determinism helpers
  (labeled SHA-256 constants, byte-stable JSON writer).
- `topic.go` / `pairing.go` / `session.go` / `phrase.go` /
  `framingvec.go` — one file per output; each transcript is generated by
  actually running both roles of the handshake and every receiver-side
  check (commitment verification, decrypt, reassembly) so a vector can
  never be emitted that the protocol itself would reject.
- `regen_test.go` — regenerates into a temp dir and byte-compares with the
  committed files (the CI drift guard), plus a two-runs-identical test.
