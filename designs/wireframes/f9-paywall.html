F9 — Paywall (every created line gated until unlock · one-time payment · store-mediated restore)

The gate exists at EVERY initiated channel until the one-time unlock is purchased — there is no free first line (USER decision 2026-07-04; supersedes the earlier first-line-free model). Joining is always free, in any quantity, with full two-way messaging. A calm full-screen page (USER decision) — price as fact, not nag. No account, no email, anywhere: purchase and restore are entirely store-mediated. Edge frame (dashed): restore on reinstall.

[App Store / Google Play purchase sheet — system UI placeholder. Face ID / fingerprint confirm, store account, store price. nimna draws none of this]
PurposeHand the money moment entirely to the platform. nimna receives an entitlement, not an identity — the store knows the buyer; the app only learns “unlocked: yes”.
Entry pointsUnlock — one payment from F9.2.
Exit pointsPurchase succeeds → F9.4. Fails or user cancels → sheet closes, F9.2 remains exactly as it was — same copy, no error banner, no “are you sure?”. Retry or leave, both fine.
Edge casesPurchase fails / cancelled → return calmly, no nagging (required edge). Interrupted purchase (app killed mid-sheet) → store settles it; next paywall visit reflects the truth via receipt check. Family sharing / regional store quirks are the store's domain — the app trusts the entitlement, nothing else.

[then straight on to F9.4's destination. If the store finds nothing: “The store has no purchase for this account.” — one line under the button, stays on this page, no drama]

PurposeProve the no-account promise survives a reinstall: the store receipt is the only memory. Restore → platform receipt check → unlocked. No email, no login, no “enter the address you bought with” — those things don't exist here.
Entry pointsRestore purchase on F9.2 — typically after reinstall or panic wipe (F8.3), when the paywall reappears because local entitlement state was destroyed with everything else.
Exit pointsReceipt found → toast “Purchase restored.” → F9.4 (on to creating). Not found (different store account, never bought) → factual one-liner, page stays, Unlock remains available.
Edge casesIAP restore on reinstall (required edge) is this frame. Restore is store-mediated end to end — annotate loudly: nimna cannot look the user up, by design; channels themselves are NOT restored (keys died with the wipe — spec §6; only the entitlement returns). Store unreachable → “Couldn't reach the store. Try again in a moment.”
