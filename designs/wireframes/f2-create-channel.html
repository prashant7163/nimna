F2 — Create a channel (initiator side)

Generate code → share → wait → key exchange → safety phrase → ready. Codes are single-use with a TTL (spec §3.1); the text code and its QR are one surface, shown simultaneously, each independently shareable (§3.1.1); the safety phrase is the closing ritual of pairing and the MITM defense (§3.1.5, §9) — call them and compare. Edge frames (dashed): code expires unused · safety-phrase mismatch.

F2.6 · Safety phrase — the closing ritual

Call them and compare

ember · canyon · plume

Read these three words to each other. If they match, the line is yours alone.

They match
They don't match
PurposeThe closing ritual of pairing (spec §3.1.5) — the MITM check phrased as the natural last step of a two-person handoff, not a warning. Both phones derive the same three words from the shared key material; comparing them out loud, over the same trusted channel the code traveled, proves nobody sat in the middle.
Entry pointsAutomatic from F2.5. The identical screen appears on the joiner's phone (F3.4) with the identical words.
Exit pointsThey match → F2.7. They don't match → F2.9 (edge frame). Destructive option is spaced below primary, never adjacent (foundations). There is no skip affordance — confirmed USER decision (2026-07-04).
Edge casesPeers can't talk right now (code went on paper, peer is remote) → they compare over any channel they trust. The spec's “strongly encouraged, not enforced” is honored by the soft skip of tapping They match — never by a skip button.

F2.8 · EDGE — code expired unused

This code expired unused.

Nothing was created. Make a new one whenever you're ready.

Make a new code
Not now
PurposeClose the loop with zero drama. Spec §3.1 failure modes: expiry means literally nothing happened — no channel, no residue. The copy says exactly that.
Entry pointsTTL lapses while F2.4 is open (state swaps in place), or on next app open if it lapsed while away.
Exit pointsMake a new code → F2.1 (fresh keypair, fresh code). Not now → F4.
Edge casesPeer tries the expired code on their side → they get F3's wrong-code error (“Codes expire — ask them to make a new one.”); the two error texts hand the pair back to each other. Silence doctrine (spec §3.1 failure modes): any later attempt on a dead code meets a rendezvous topic that no longer exists and receives silence — no failed-attempt notification is ever surfaced, to either side, ever. There is nothing actionable to report, and a discretion product does not manufacture anxiety.

Make a new code
Not now
PurposeThe MITM defense working as designed (spec §3.1.5, §9). Tone stays level: state what it can mean, state what was done (everything discarded), point forward. No sirens, no red.
Entry pointsThey don't match on F2.6 (or on the joiner's F3.4 — both sides land on their own copy of this screen once either declines).
Exit pointsMake a new code → F2.1. Not now → F4. Either way the discarded pairing is unrecoverable — keypairs deleted on both sides.
Edge casesFalse alarm (misread word) → cost is one minute: make a new code. Design accepts false positives cheerfully; the asymmetry (cheap redo vs. silent interception) is the whole point.
