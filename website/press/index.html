Boilerplate

Nimna is a private line between two people: a paid, account-less messaging app in which conversations exist only on the two paired phones. There are no accounts, no server-side storage, and no message queues — the open-source relay routes end-to-end-encrypted data between two live connections and keeps nothing, a claim anyone can verify in its public source code. Conversations are synchronous, like a phone call in text form; messages written while the other person is away wait on the sender's device alone. The name comes from the Sanskrit निम्न (nimna): low, deep, beneath notice.

Facts

  • Platform: iOS and Android (Flutter)
  • Price: first created line free; one-time unlock for unlimited; joining always free; no subscription, no accounts
  • Relay: open source, stateless, no database — source
  • Status: in development; protocol spec v0.1 public in the repo
